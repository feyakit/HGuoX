**项目定位**：`HGuoX`（当前版本 `3.0.20`）是一款基于 **Rust + Tauri 2 + React 19** 构建的跨平台短剧 / 漫剧客户端，一套代码覆盖 **Android、iOS、Windows、macOS、Linux** 五大平台，围绕「莫比乌斯极光玻璃视觉、双模式沉浸追剧、国内复杂网络并发选线」进行深度工程化打磨。

## 核心功能

### 视觉与多端适配

- **莫比乌斯极光玻璃 UI**：深色极光画布配合磨砂玻璃浮层与无过冲 GPU 阻尼动效；支持 Android Adaptive Icon 与 iOS / Android 深色防闪白原生启动页。
- **封面实时取色氛围系统**：自动提取当前剧集封面主色并计算暗调背景与多层氛围强调色，在播放页非视频区与剧集详情页顶部实时渲染专属氛围光晕。
- **五端自适应交互**：手机端采用悬浮玻璃底栏与安全区适配，桌面端支持无边框窗口（Windows / Linux 自定义标题栏与边缘缩放、macOS 原生融合）、可折叠侧边栏与剧场右侧停靠面板。
- **统一按钮与圆角体系**：全站按钮收敛到品牌渐变 `#7C5CFF → #5B6BFF` + 1px 白内描边（主 CTA 高 44 / 圆角 12），圆形图标按钮视觉 36 / **热区 44**；卡片圆角收敛到三档（大容器 20 / 普通卡片 16 / chip 999），顶栏 tab 视觉高度不变但热区补到 44。
- **设置页重做**：由「概览卡 + 三个圆形入口 + 六张折叠卡」改成 **7 组平铺 15 行**（播放 / 内容偏好 / 网络 / 本地数据 / 播放诊断 / 账号 / 关于），同一个值全页只出现一次；退出登录从「我的」页底部移入 **设置 › 账号**（风险色 + 二次确认）。

### 发现、片库与吃瓜社区

- **首页三态编排**：官方口碑推荐横滑轮播展台（跟手拖拽 + 错峰避重）+ 热播风向标 TOP 10 + 16:10 宽画幅原创 + 首发上新流 + 金银铜 3D 领奖台热榜，支持触底自动加载与二级页返回保留原滚动位置。
- **片库、发现与去重**：2×2 Bento 玻璃分类磁贴、跨模块智能去重、一键「换一批」淘片刷新、专题策展合集与自定义标签内容屏蔽。
- **吃瓜社区**：采用「时间线（按日期分组）+ 热议榜」双视图，对齐黑料吃瓜与短剧剧评分类并自动去重，桌面端同步提供侧边栏入口。
- **个人中心**：主页直出「最近观看」横向续播卡片条（带进度与一键续播），支持账号云端同步、短剧 / 吃瓜双栏收藏与浏览历史。

| 🚀 **预热与缓存** | 只读接口内存缓存与并发去重、页面分包空闲预加载、下集 / 下条 HLS 播放列表预热 |

## 网络与自动选线

针对国内复杂网络与代理环境，Rust 网络层做了专项优化：

- **并发竞速自动选线**：主站探测（保留 1 秒优先窗口）与发布页拉取并发执行，命中首个可用镜像后 **350ms 早停收口**，避免被失效节点拖慢；探测专用请求（`edge_once`）关闭重试退避，单节点超时收敛至 3 秒。
- **缓存与快速降级**：发布页内置 5 分钟内存缓存；业务接口失败时直接触发自动选线切换，播放页内支持随时就地换线。
- **复杂代理原生兼容**：原生兼容主流代理工具 TUN FakeIP（`198.18.0.0/15` / `fdfe:dcba:9876::/48`）、运营商 5G NAT64（`64:ff9b::/96`）与 DoH 加密解析兜底。
- **FakeIP + IPv6 ULA 修复（3.0.9，`22cca21`）**：开 Clash / Stash / sing-box / Shadowrocket 这类 TUN 代理时，系统 DNS 会同时返回 fake-ipv4 与合成的 IPv6 ULA，旧逻辑对整组地址校验、遇到合成 ULA 就**整次拒绝**，表现为全站请求失败。现在改为滤掉不可放行地址、保留合法 fake-ipv4，**私网白名单没有放宽**。
- **线路自愈（3.0.7）**：① 发布页与固定线路域名**优先走加密 DoH 解析**（国内 DNS 污染会把主站指到公网 Facebook 段）；② 发布页两页并发、**先到先用**（另一页只再等 2s，页面预算 6s→12s）；③ 解析出的镜像列表**落盘兜底**（只当探活候选）；④ 候选 <3 时用**内置种子**补位，逐条真探活；探活预算 3s→5s。落盘缓存与种子只用于切换、**不授予登录凭据信任**（`trusted_auth_origin` 边界不变）。

## 使用说明

1. **线路切换**：如遇默认线路较慢，可在播放页控台或 **设置 › 网络与线路** 手动切换或触发自动优选；支持在 **设置** 中导出脱敏网络诊断信息用于排查问题。
2. **内容偏好**：可在 **设置** 中配置标签屏蔽，过滤不感兴趣的内容分类。
3. **刷新数据**：首页 / 吃瓜 / 分类 / 榜单四个页面支持**下拉刷新**（强制拉最新，成功提示「已同步官网」）；从后台切回、以及前台每 5 分钟会自动静默刷新，不用手动重进。
4. **退出登录**：在 **设置 › 账号**（「我的」页不再放退出块）。
5. **升级兼容**：本地收藏、观看记录、偏好与主题使用 `hguox_*` 存储键；首次启动时会自动兼容迁移同空间下的旧 `hghub_*` 数据。
6. **包名变更（3.0.9）**：从 `com.hguox.app` 换成 `com.dusk.player`，**WebView 存储空间随包名走**，所以旧包的收藏 / 历史 / 登录态都不会自动继承。升级等于换一个应用：可以卸载旧包再装新包，也可以让两者并存；旧包数据留在旧包里，不做导出。

## 开发

技术架构、本地开发调试、多端构建与自动化测试的完整说明见 [DEVELOPMENT.md](DEVELOPMENT.md)。这里只放最常用的信息和目录地图（3.0.9 起前端目录已对齐上游 `app / features / shared`）：

```text
src/
├── app/          # App 壳：App.tsx、shell/（底栏与导航栈）、startup/（启动动画与启动锁）
├── features/     # 按业务域切：feed / category / discover / posts / playback / search / account / settings
├── shared/       # 跨域共享：api（命令与数据）、model（store）、network（autoLine / linePolicy）、
│                 #   storage、ui（卡片与 iOS 风格控件）、lib（usePullToRefresh 等）、diagnostics
└── styles/       # ios.css / shelf.css / launch.css / ambient-glow.css 等视觉层
src-tauri/        # Rust 原生层：api / media / lines / net（DoH 与 fake-ip）/ session / playback_log
scripts/          # test-*.mjs 回归脚本、set-version、图标生成、check-legacy-css
docs/             # 控件清单、已知问题、遗留问题、上游同步评估、线路策略、release-notes
```

```bash
pnpm install --frozen-lockfile   # 装依赖（Node 22+ / pnpm 10+）
pnpm dev                         # 纯前端开发服务器
pnpm tauri dev                   # 桌面端（Tauri）调试
pnpm android:dev                 # 连真机 / 模拟器跑 Android
pnpm build                       # tsc ×2 + vite build + check-legacy-css（提交前必跑）
pnpm app:build                   # 打桌面安装包
pnpm android:build               # 打 Android APK
```

改代码后至少要让 `pnpm build` 全绿（里面已含 `node scripts/check-legacy-css.mjs`：老内核 WebView 不支持的 CSS 特性会直接失败）。
