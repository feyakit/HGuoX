# HGuoX 3.0.9

> 这一版是三件事的合集：**吃瓜帖子内下滑闪屏的两个根因都修掉了**（安卓的 DOM 重建、iOS 的滚动合成），**跟上上游 2.2.6 的十九项修复与功能**，以及**一次纯结构搬家**（目录对齐上游，产物字节级不变）。

## 一、闪屏：两个根因，分别修

### 安卓：滚动重写 innerHTML → 正文图片全量重建

- **根因**：详情页滚动时整块正文 `innerHTML` 被重写（触发源是内嵌播放器每帧变化的 `value` / `--fill`），正文里 6 张 `<img>` 被逐个销毁重建 → 重新解码 → 隔帧重画。
- 云机实测（旧包）：2.2 秒滚动 `<img>` 重建 **222 次**，60fps 亮度跳变 **52 次**；新包：**0 次 / 0 次**。
- **修法**：正文 `dangerouslySetInnerHTML` 的属性对象按「正文 / 安全模式」缓存复用，内容不变时 React 不重写 HTML；同时保留内容不被线路/代理事件清空，缓冲转圈延迟 300ms 防抖。

### iOS：`-webkit-overflow-scrolling: touch` 触发的合成丢块

- **根因**：该属性把滚动容器交给 UIScrollView 做异步分块栅格化，叠加详情页 `position: fixed` 悬浮底栏与 `backdrop-filter` 顶栏后出现「丢块再补」的可见闪烁。Chromium 完全忽略该属性，所以安卓侧始终测不出来。
- **定位方式**：真机三版二分 —— 三处全删不闪 → 恢复 `backdrop-filter` 仍不闪 → 再恢复 `contain: paint` 仍不闪，唯一变量落在该属性上。
- **修法**：删掉该属性（iOS 13+ 由 UIKit 统一接管，属冗余声明；上游全仓库 0 处使用）。磨砂与 `contain: paint` 均保留。

### 图片代理真正缩图

- `cover(url, w, h)` 的宽高不再被忽略，Rust `/img` 带 `w`/`h` 时解码后缩放并按 `u|w|h` 做缓存键；长图高度上限 1600。
- 1080×8000 的长图解码 29.1ms → 1080×1600 后 8.3ms（−71%），详情页首屏更稳。

## 二、上游 2.2.6 及同期修复

### 功能性

- **DNS fake-IP 修复（关键）**：开启 Clash / Stash / sing-box / Shadowrocket 等 TUN 代理时，系统 DNS 会同时返回 fake-ipv4 与合成 IPv6 ULA，旧逻辑对整组地址校验、遇到合成 ULA 就整次拒绝，导致全站请求失败。现在改为滤掉不可放行地址、保留合法 fake-ipv4，**不放宽私网白名单**。
- **线路切换后保持登录**：切线路、重启都不掉登录态。
- **返回收藏列表刷新可见卡片**：返回时重新校验封面/点赞数/是否在架，每张卡每次返回只重拉一次。
- **键盘弹出时登录表单不被遮挡**、**移动端安全区按视口生效**、**全屏/返回/键盘守卫**、**启动遮罩接管 Android 返回**、**零闪烁启动**。
- **Rust media/proxy/session 硬化**：只取护栏，不拆模块。

### 功能

- 收藏页：观看进度、**「新更 N 集」徽标**、**长按多选**、**批量全选**、滚到底自动加载。
- 详情页主按钮改「继续看第 N 集」（看完这集自动跳下一集）。
- 拖动进度条时高亮底栏、去掉挡屏的中央定位浮层。
- 「我的」↔频道、榜单三 tab 支持左右滑切（新增 `useTabSwipe` / `useRankSwipe`，避让列表纵向滚动与点击）。
- 频道/分类封面上角标（真实数据驱动，集数药丸位置未变）。
- 详情/选集抽屉支持左右滑切页与顶部下拉关闭。
- 标签长按屏蔽，判定沿用「手指在动就不算长按」。
- 播放器微光效果（32×18 采样填黑边），并删掉旧的封面虚化实现。

## 三、播放器

- **上下集切换改整页 pager**：视频+标题+进度+底部控件整体跟手，12% 出预览、25% 或 600px/s 提交、220ms 缓动、未达门槛 180ms 回弹。
- **全屏控件 1.2s 收起**（退出全屏恢复 3s）。
- **结束态「重新看第 1 集」真的回 0 重播**；结束态上滑一次关卡片，再滑能正常切集。
- 横屏全屏切集提示只弹一次；播放提示统一单槽。
- 清屏锁定后锁图标不再常驻；移除「拖到顶部胶囊锁倍速」，只留长按 2x。
