# HGuoX 3.0.15

> 围绕「播放器屏蔽入口极简收敛、置顶标签联动抖音模式随机流、我的收藏状态筛选与排序、Windows 桌面全屏修复与官网热搜对齐」发版。

## 一、播放器交互极简收敛（方案 A）

- **右侧操作栏回归三键**：移除移动端播放器右侧操作栏最底部的 `•••` 屏蔽/不感兴趣按钮（及桌面端左下重复入口），右侧恢复为「点赞 / 收藏 / 评论」三颗高频互动钮，并同步校准垂直居中锚点。
- **长按统一 2x 倍速**：移除播放画面中央方块长按弹屏蔽菜单的分支，长按画面任意区域均稳定触发 2x 倍速，不再误触打断播放。
- **标签屏蔽统一收口**：保留明确且不干扰观影的入口——视频详情页「调整内容偏好」与长按标签芯片、标签详情页「屏蔽此标签」、设置 › 内容偏好 › 屏蔽标签。

## 二、上游高价值功能与修复移植

- **置顶标签驱动抖音模式随机抽样（`port(8888bda)`）**：配置置顶标签后，抖音模式优先并发从置顶标签随机抽样并循环洗牌，置顶标签下暂无可用剧目时无缝回退全站随机；未配置置顶标签时保持原有全站随机逻辑。
- **我的收藏状态筛选与排序（`port(3a0de00 + 61f5a55)`）**：收藏短剧页新增「全部 / 未看完 / 连载中 / 已完结」筛选条；切到状态筛选时按最新更新时间降序排列，且「连刷收藏」与「批量全选」自动遵循当前筛选结果。
- **Windows 桌面端原生窗口全屏修复（`port(5a3a1f0)`）**：Windows 无边框 WebView2 下改用 Tauri 原生窗口全屏 + `data-desktop-fs` 清除合成层属性（支持 `Esc` 退出），规避 16:9 横屏全屏黑屏问题。
- **官网热搜 URL 对齐（`port(c456571)`）**：热搜抓取改用官网标准 `/search/` 地址，去掉自定义查询参数。
