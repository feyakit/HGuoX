# HGuoX 3.0.13

> 继续按「少一点误触、顺一点手感」改播放器。这一版把单击/双击的分工换成 B 站式（单击唤出菜单、双击暂停），把上下滑从「提交式」改成跟手，并把右侧按钮组与底部信息条重新排版。

## 一、手势：单击唤出 / 双击暂停

| 手势 | 3.0.12 | 3.0.13 |
|---|---|---|
| 单击 | 暂停 / 播放 | **唤出 / 收起控件**（250ms 内确认不是双击才执行，避免双击时控件闪一下） |
| 双击 | 点赞 | **暂停 / 播放**（暂停时控件常驻，不自动收起） |
| 长按 | 2x | 2x（优先级最高，按住即作废单击/双击） |
| 点赞 | 双击画面 | **只在右侧按钮**（画面中央红心动画已删除） |

按钮命中不进 250ms 延迟，点按钮立即生效。

## 二、上下滑改成跟手 pager

以前是「提交式」：拖动时画面不动、只显示预览提示，松手过了阈值才切——所以手感是「划了没反应，突然跳一下」。

现在：拖动时画面 1:1 跟着手指走，相邻项有 0.35 阻尼；松手判定为 **位移 > 舞台高 24% 或 速度 > 0.5px/ms** 就切，否则 200ms ease-out 回弹。起手 8px 内锁定主方向，不会和横滑/进度条拖动互抢。横屏中区保留 48 CSS px 保底阈值（横屏舞台只有约 360 高）。

首集下滑仍然只回弹并提示「已经是第一集」，末集上滑才出结束卡——3.0.12 的行为不变。

## 三、「全屏观看」入口并入控件层

视频下方那行「全屏观看」以前常驻，现在跟着控件一起收起/唤出。位置与尺寸不变（高 44、距画面底边 8、图标 16、文字 13）。

同时**删除右上角的全屏按钮**——入口只保留视频下方一处，避免两个入口让人困惑。

## 四、竖版片源锁竖屏

看竖版剧时手机横过来，界面不再跟着转（转过去还是同一条竖版画面 + 两侧黑边，纯损失）。规则：

- 竖版片源 → 播放期间锁 `portrait`
- 横版点「全屏观看」→ 锁 `landscape`
- 退出全屏 → 回 `portrait` 并重新锁
- 离开播放页 → 方向控制权还给系统

## 五、右侧按钮组与底部信息条排版

- 「更多」从右上角并入右侧竖排，成为竖列最后一项；间距统一 14（横屏 10）；整组垂直锚定画面 58% 处；热区统一 44×44，图标 24（点赞 26）；距右边缘 `--sar + 12`
- 底部「集数 / 详情 / 站点域名」改为固定三段：集数胶囊定宽 88、详情 `flex-1` 单行省略、域名隐藏时保留占位；行高 32、段间距 8。此前这一行会因条件渲染整体重排（一会儿在上一会儿在下、间距忽大忽小），现在位置固定

## 六、验证

- harness：单击延迟、双击暂停、长按优先、按钮不进延迟；全屏行随 idle 隐藏；跟手采样（每 16ms 采样画面位移与手指位移，偏差 ≤1px）；首集回弹、末集结束卡
- `pnpm build`（tsc ×2 + vite）与 `check-legacy-css`（5 个产物 0 违规）绿
- 回归：手势单测、既有 harness 全绿

## 已知限制

- 亮度与音量是 WebView 内 CSS filter 与 `video.volume`，adb 无读数，验收靠肉眼
- 未登录状态下的点赞失败回滚、可控弱网下的失败提示无法在现有设备构造
- iOS 只有未签名 IPA（需自行签名）
