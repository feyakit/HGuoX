## 四、约束确认

抖音模式 / 剧场模式、全屏口径（视频下方「全屏观看」+ 横屏只左上角返回）、手势分工（单击暂停 / 双击点赞 / 长按 2x / 横屏三区）**均未回退**；UI 布局与尺寸未改。

## 已知限制

- iOS 只有未签名 IPA（本轮未在 Mac 上做签名构建）
- 亮度和音量是 WebView 内 CSS filter 与 `video.volume`，adb 无法读数
- 未登录状态下的点赞失败回滚、可控弱网下的失败提示无法构造
