# HGuoX 3.0.14

> 围绕「上游 `dx150-edge-v1` 加密网关适配、弱网自动换线自愈、Android 播放稳定性修复、发现与搜索体验补强」发版，完整保留现有 UI、抖音模式与剧场模式设定。

## 一、网络与加密网关（P0）

- **适配 `dx150-edge-v1` 四作用域加密网关（`port(a6b3f15)`）**：解决上游下线旧 `/api/edge/request` 返回 503 的问题，按作用域路由至 `/api/{public,dynamic,playback,user}/request`，复用 `ring` 实现 ECDH P-256 + HKDF-SHA256 + AES-256-GCM 单飞会话加解密；`public` 优先走 `X-HG-Public-JSON: 1` 快速路径，对未迁移镜像保留旧接口 `404/405` 兼容回退。
- **链路层硬错误自动换线与容错**：仅对 DNS / TLS / Reset / Refused / Timeout 等链路层错误计数与拉黑，支持两轮自动换线重试与备用线路切换提示；严格保留用户手动/自定义线路不被自动覆盖；`403` 不再冒充 `401` 误触发重登；错误页提供通俗说明并默认折叠原始错误详情。
- **DoH 兜底与诊断增强**：补齐阿里 / 腾讯 / Cloudflare DoH 兜底与系统 DNS 对照诊断。

## 二、Android 播放页稳定性（P1）

- **修复 Android WebView 播放页闪烁（`port(3043c8b + 34da719)`）**：仅在 `.plat-android` 播放页关闭压在 `<video>` 上的 `backdrop-filter`；微光效果在 Android 改为 `8×5 @ 250ms` + GPU 双线性放大替代全屏 `blur(44px)`；未缩放时移除冗余 `translate3d` 合成层，Android 进播放页跳过入场动画。
- **被遮盖层释放后台解码器**：新增 `LayerBox` 与 `PageCoveredContext`，上层栈页覆盖时释放底层 `<video>` 解码器并暂存进度（画中画不中断），返回后无缝续播；栈深度上限收口至 8。

## 三、发现、搜索与细节体验

- **首页与热门题材对齐官网**：首页 Hero 展台按官网 `api_home.banners` 顺序展示；搜索页热门题材按官网首页 SSR 同步并支持 `10+10` 分页与强制刷新。
- **频道与标签增强**：
  - 标签页支持**长按置顶**与标签详情页标题栏**一键图钉置顶**（最多 24 个），同时过滤掉 `0` 视频的空标签。
  - 频道页与标签结果页新增**指标排序**（默认 / 播放量 / 评分 / 点赞数 / 收藏数，支持升降序切换），标签结果页新增**连载状态筛选**（全部 / 连载中 / 已完结）。
  - 完结剧目卡片角标显示「全 N 集」。
- **搜索与设置**：
  - 搜索历史支持**长按批量删除**。
  - 设置 › 播放新增「**启动时打开的页面**」偏好（首页 / 吃瓜 / 分类 / 我的）。
  - 标签置顶与吃瓜帖子收藏提示共用单槽不堆叠；修复窄屏下统计行异常折行。
