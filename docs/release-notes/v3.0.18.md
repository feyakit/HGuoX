# HGuoX 3.0.18

> 底栏重做：更小、更透、位置按系统安全区自适应。首页「继续观看」浮卡随之下沉缩小。

## 一、底栏（底部导航）

| 项 | 3.0.17 | 3.0.18 |
|---|---|---|
| 胶囊高度 | 66 dp | **56 dp** |
| 占屏宽 | 92% | 约 78% |
| 距屏幕底 | 36 dp（固定 padding 累加） | **8 dp + 真实安全区** |
| 图标 / 字号 / item 间距 | — | **20 / 10.5 / 4** |
| 玻璃 | alpha 偏高、blur 28 / saturate 180 | **alpha −0.22、blur 24 / saturate 160** |

## 二、安全区改成运行时自适应（不再硬编码）

以前底部安全区是一个固定值，在 3 键导航 / 手势导航 / 横竖屏之间不会变，所以要么压住手势条、要么悬空。现在：

- **Android**：Kotlin 侧读 `WindowInsets`（`navigationBars` / `mandatorySystemGestures` / `systemGestures` 三者取最大值），除以 density 后写入 CSS 变量 `--sab`
- **监听变化**：`setOnApplyWindowInsetsListener` + `onConfigurationChanged`，切换导航模式（手势 ↔ 三键）、横竖屏旋转、系统设置变化时自动重算，**不需要重启 App**
- **iOS / 桌面**：用 `env(safe-area-inset-bottom)`，拿不到时为 0（不再用硬编码 24 兜底）
- 底栏与浮卡统一 `bottom: calc(8px + var(--sab))`，任何机型任何导航模式都不会压到手势条

## 已知限制

- 三键导航与手势导航的切换验证取决于机型的 MIUI/ColorOS 是否允许通过 adb 改 `navigation_mode`；不允许时会如实标注"该组未验"，不编数据
- 亮度与音量仍为 WebView 内 CSS filter 与 `video.volume`，adb 无读数
