# HGuoX 3.0.10

> 3.0.9 发布后用户在播放页撞到四个问题（底栏按钮按不动、切集出现两个提示、长按/双击失效、右上按钮位置会变），加上一份第三方静态审计提了 19 条。这一版把两边**全部修完**，并且每一条都有可复现证据。

## 一、播放页：用户直接撞到的四个问题

| 问题 | 根因 | 修法 |
|---|---|---|
| 底栏「倍速 / 上一集 / 下一集」点了没反应 | `.hg-seg-pill::after` 那个 44px 热区伪元素绘制在静态子按钮**之上**，点击全落在容器 `div` 上（自 3.0.8 引入） | 热区改挂到按钮自身 `.hg-seg::after` |
| 切集时出现两个「下一集」提示，其中一个不消失 | 拖动预览 `epPreview`（z-30）与换集 toast 是两条独立提示，提交分支每条都 `return`，没人清预览 | 提交时统一 `setEpPreview(null)`；提示只留一条，超时必清 |
| 长按 2x / 双击三分失效（仅控件收起时） | clean 态那层 z-25 捕获层在 `pointerdown` 就 `stopPropagation` | 删掉该拦截层 |
| 右上角按钮位置会变 | 竖屏写死 `right-3`、全屏写死 `56px`、伪横屏却用底部安全区 `--sab` 当横向偏移 | 统一吃左右安全区 `--sar`，控件组固定两格 |

## 二、全屏：只保留系统真转屏

- 删除 CSS 伪横屏整条路（`rotated` / `fsLandscape` / `vpLandscape` 判断 / `.fs-landscape`）——之前两套机制并存，导致「点了全屏但视口没转」的不确定行为。
- `fs` 一旦为真就调系统方向接口；**失败不再偷偷走伪横屏**，而是停在竖屏沉浸全屏并提示「系统未允许横屏」。
- 控件自动收起统一 **3 秒**（原来全屏单独 1.2 秒），控件隐藏时退出全屏一步可达。
- `set_orientation` 失败不再被 Rust 侧吞掉，会作为错误返回给前端。

## 三、静态审计 19 条（全部修复）

**高**
1. 登录超时后界面仍是游客但令牌已写入 → 超时后主动核对会话，界面与令牌必须一致
2. 桌面全屏锁屏后解锁罩不在全屏元素内 → 全屏时上锁先退全屏（仅桌面路径）
3. 播放中切线路从 0 重播 → 切线保留 `currentTime`；线路去重按归一化 host（尾斜杠/大小写不再误判）

**中**
4. 大于 4MB 的分片带 Range 会整段重下 → `/seg` 把单段 `Range` 透传上游（实测 CDN 回 206），非法 Range 416、上游回 200 时退回整段切片；同时挡住 m3u8 子清单误入
5. 读缓存键不含用户、`hg:account-changed` 无人派发 → 缓存键加线路代次与账号作用域，登录/退出/切账号派发事件；点赞数改为「服务端计数 + 本地增量」
6. 吃瓜列表翻页无请求序号 → 加代次，旧页不再接上新列表
7. 点赞增量换线后不撤销 → 换线重置本地增量
8. 转屏失败被静默吞掉 → 见第二节
9. 详情慢 >3s 会绕过「自动选线」开关改线路 → 走同一入口，尊重开关与偏好
10. 结束卡推荐可被更慢的上一次请求盖回 → 推荐池加代次守卫（8 秒时序可复现，已修）
11. 专题/标签/频道换线后旧列表接新页 → 加载依赖加线路代次，换线清列表重拉
12. 榜单/货架旧响应覆盖新数据并写「刚更新」→ 两处都加请求代次
13. 分类第 1 页后台刷新抹掉后续页 → 刷新只合并第 1 页范围
14. 收藏卡「新更 N 集」点开不消失 → 已看集数等于基线时也认账（点开即抬基线）
15. 收藏与历史条数相同时滚到底不再加载 → `useAutoLoadMore` 依赖补 `resetKey`
16. 详情页收藏数静默刷新后 ±1 → 服务端已含本次操作时清本地增量

**低**
17. 控件收起时双击第二下打到刚出现的按钮 → 收起态第一下也进双击判定窗口
18. 横滑松手进度条先回跳再跳回 → 松手先发布目标时间再清预览
19. 分类排序 chip 的 44px 热区被 `overflow-x:auto` 裁成 ~32px → 容器改 `overflow: visible`

## 四、其他

- 结束态「换一批」改为**真实轮换池**：`related` 全量 + `feed` 多页合成池，每批往后移 3 部、排除已展示；轮完一遍会提示「推荐已轮完一遍，从头开始」；拿不到新内容如实显示「暂无更多推荐」，不重复同一批。
- 吃瓜列表在线路事件后不再清空重建（已渲染卡片节点保持存活），只静默刷新数据。
- 分类页片库区支持左右滑切换子 tab，不抢纵向滚动与卡片点击。
- DNS fake-IP：代理合成的 IPv6 FakeIP（ULA 段）不再被固定给连接器（不可直连），与上游 `70d5120` 行为一致。

## 五、验证

- **真机（小米九 + Mac AVD）**：49 项全量 + 定向回归；底栏三按钮逐点命中 `BUTTON`、切集提示单条且 ≤2s 清除、长按 2x 与双击三分在 clean 态恢复、全屏为真横屏且可一步退出。
- **审计 19 条逐项**：18 条通过 + 1 条 N/A（桌面专属）；其中 12 条靠容器 harness（mock Tauri IPC + 真 HLS + 真组件）造出多线路、多账号、8 秒延迟、插件报错等真机无法构造的条件。
- **Rust**：`cargo check --all-targets` 与 `cargo test --lib` 在 Oracle 宿主机 docker（`ubuntu:24.04` + rustc 1.100）中全绿。
- **构建**：`pnpm build`（tsc ×2 + vite）与 `check-legacy-css`（5 个产物 0 违规）全绿。

## 已知限制

- 桌面全屏锁屏那条（审计 #2）只在桌面 Fullscreen API 路径，移动端不走该路径，本次按 N/A 记录。
- 详情页收藏数在「服务端返回未含本次操作」时会回落 1，属既有设计取舍（避免虚高），如需改为「取本地与服务的较大值」可后续调整。
- iOS 端仍无法提供 DOM 级取证（`ios_webkit_debug_proxy` 不支持 iOS 17+ 的 `remoted` 通道），iOS 结论来自真机目视与二分实验。
