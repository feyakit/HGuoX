# HGuoX 3.0.17（Android）

> 修复首页 Hero 宽幅图与多处横版卡片封面裁切问题。

## 修复内容

- **首页 Hero 图按真实比例自适应**：官网宽幅 `banners` 默认按 `16:9`（`56.25%`）渲染，并在图片加载后根据自然宽高动态适配（手机端 `40%–64%`、宽屏 `34%–48%`），不再将宽幅图左右大幅裁切；回落竖版封面时保留 `64%` 且改为偏上对齐（`center 22%`）防止切头。
- **吃瓜时间线头图与帖子封面**：比例统一调整为 `16:9`（`56.25%`）并偏上对齐（`center 25%`），减少上下裁切与切脸。
- **首页原创横卡与专题卡片/头图**：统一 `16:9` 比例并补充 `object-position: center 22%`，防止人物封面头顶被裁切。
