# 播放页控件清单（W19）

> 说明：`docs/控件清单.md` 是 W11 的**全 App 控件像素实测表**（尺寸/圆角/取色），本文是**播放页有哪些控件、该不该留**的功能清单，两者互补，不合并。
>
> 判定标准：**只留「看剧」这件事需要的控件**；凡是跳去别的页、做任务、发奖励、做推广、外链的一律不留。
> 适用范围：移动端播放页（`src/features/playback/EpisodePlayer.tsx` 的 `isDesktop === false` 分支）。桌面端见文末。
> 本文最后对齐版本：**3.0.9**（3.0.8 → 3.0.9 的全部控件变化见文末「3.0.9 变化」一节）。

## 本轮（W19）删掉的

| 控件 | 原行为 | 为什么删 |
|---|---|---|
| 「设置 · 线路」 | `store.push({ kind: "settings" })` → 直接跳出播放器到全应用设置页 | 看剧时点「设置」无从理解；线路已改为**就地切换**（#16），不再需要跳页 |
| 搜索 🔍（播放器右上） | `store.push({ kind: "search" })` → 跳全站搜索页 | 播放页里的外跳入口，与「只看剧」冲突 |

## 保留说明（两类有争议的，写清依据）

1. **点赞 / 收藏 / 评论**：不在「只留看剧」的字面清单里，但它们都是**就地完成**的互动（不跳页、不开新路由），而且是 3.0.0 回归报告专门测过计数显示的三项。删掉等于砍功能，用户下一轮大概率会问「我的收藏呢」。**保留**；若产品要按最严口径再收敛，单独开一条，不要和修 bug 混在一起。
2. **锁定播放控制 / 上下划切集开关 / 画质**：都是就地生效的**播放器行为开关**，不写账号、不跳页，属于「看得舒服」的一部分。保留。

## 桌面端（本轮未动）

`PlayerControls` + 桌面右栏还有：上一个/下一个、选集、评论、分享、剧场模式、画中画、音量滑杆、全屏（浏览器 Fullscreen API）、详情与标签、不感兴趣。按同一标准大多合规（全部就地生效）；**桌面端播放器里本来就没有「设置」入口**。

## 手势表（3.0.9 口径）

判定逻辑全部在纯函数层 `src/features/playback/playerGestures.ts`（常量 `GESTURE` / `PLAYER_TIMING`），组件只负责喂输入与画反馈；
单测 `scripts/test-player-gestures.mjs`（49 条）覆盖下表的每一条，也断言 `PLAYER_TIMING` 的 3s / 1.2s 与 pager 的 25% / 600px·s⁻¹ / 300ms / 180ms / 160ms。

| 手势 | 判据 | 结果 |
|---|---|---|
| 起手死区 | 位移 < **10px** 不定方向 | 无动作（既不 tap 也不 seek） |
| 单击 | 总位移 < 6px 且时长 < 300ms | 控件收起 → 唤回；控件显示 → 暂停/继续 |
| 双击窗口 | 两次点击间隔 < **280ms** | 按 **三分法** 判定（见下两行） |
| 双击 · 左 1/3 | `x < 宽 × 1/3` | 退 **5 秒** |
| 双击 · 中 1/3 | 宽 × 1/3 ≤ `x` < 宽 × 2/3 | 播放 / 暂停 |
| 双击 · 右 1/3 | `x ≥ 宽 × 2/3` | 进 **5 秒** |
| 方向锁 | 超过死区后 `abs(dx) ≥ abs(dy) × 1.4` 判横、`abs(dy) ≥ abs(dx) × 1.4` 判竖 | **定下即锁死**，同一手势内不再改判；斜 45° 继续等 |
| 横向拖动 seek | 位移 ≥ 20px | 100px 对应：片长 ≤60s → 15s、60–600s → 30s、>600s → 60s；松手吸附到整 5 秒，气泡停留 800ms |
| 竖向拖动换集（整页 pager） | 跟手位移同时作用在「视频 + 标题 + 进度 + 控件」整层（4% 缩放 + 淡出，占位页从 ±100% 进入）；拖过屏高 **12%** 露集数预览，**25%** 或速度 ≥**600px/s**（且位移 >160px）松手提交 | 上滑下一集 / 下滑上一集；提交 **300ms**（`.16,1,.3,1`）、未达门槛 **180ms** 回弹、标题淡出淡入 160ms；`swipeEp` 关闭时整条手势不接管 |
| 长按 | 600ms | 临时 **2x** 快放，松手恢复；3.0.9 起没有「上滑锁定常速 2x」、没有「下滑 0.5x」、也没有拖到顶部胶囊的锁定目标 |
| 左缘返回 | 起手 `x < 24px`、右滑 ≥ **72px** | 退出播放页 / 退一层 —— **仅非全屏态**；全屏（`fs`）与物理横屏（`vpLandscape`）下**一律禁用**，同手势改判为 seek |
| 旋转冷却 | 方向切换动画期间 **300ms** | 不吃手势（防转屏瞬间误触） |

> 与 3.0.6 的差异：双击从「左右对半、步长 10s」改成「三分法、步长 5s」；全屏三态禁用左缘返回；
> 这三条都是用户在真机上反馈「中间区域误触暂停」「想快退结果退出全屏」后的改动。
>
> 与 3.0.8 的差异：换集门槛 40%/70% → 12%/25%（并加 600px/s 速度辅助），长按只保留 2x 临时加速。

## 3.0.9 变化（3.0.8 → 3.0.9）

> 数值来源：`src/features/playback/playerGestures.ts`（`GESTURE` / `PLAYER_TIMING`）、`EpisodePlayer.tsx`、`Settings.tsx`、`PlaybackLock.tsx`，以及 `scripts/test-player-gestures.mjs` 的断言。

| # | 项 | 3.0.8 及以前 | 3.0.9 | 代码位置 |
|---|---|---|---|---|
| 1 | 上下切集 | 只有视频层跟手轻推，标题/进度/控件不动；门槛 40% 提交、70% 露预览 | **整页 pager**：视频 + 标题 + 进度 + 底部控件整层位移（4% 缩放、淡出），下一屏占位从 ±100% 进入；**12%** 露预览、**25%** 或 ≥600px/s 提交（速度辅助还要求位移 >160px）；提交 300ms、回弹 180ms | `EpisodePlayer.tsx`（`epSlide` / `pageProgress`）、`GESTURE` |
| 2 | 控件自动收起 | 竖屏与全屏都 3s | 竖屏与全屏**统一 3s**（全屏/沉浸专属的 1.2s 已删） | `PLAYER_TIMING.autohideMs`（唯一来源） |
| 3 | 播放提示 | 各调用点各弹各的，快速切集会叠一摞 | **统一单槽** `playback-hint`：同 tag 原地替换（切集提示、上一集/最后一集、上下划开关、画质回落…），不堆叠；横屏全屏切集提示等新片舞台就绪后**只弹一次** | `EpisodePlayer.tsx` `queueEpisodeToast()`、`store.tsx` `toast(msg, kind, tag)` |
| 4 | 拖动进度条 | 屏幕中央弹一块大时间浮层，挡住画面；底栏没有明显反馈 | **删掉中央浮层**。改为底栏高亮：轨道 3→**6px**、底色 .24→.30、已播段加 12px 品牌色光晕；进度点 10→**14px** 并加一圈白晕；拖动中的时间胶囊只在**进度点上方**（`-top-8`）出现。双击 / 松手 seek 的瞬时提示是左右 1/3 位置的小胶囊，800ms 消失（右侧有快捷栏时再内让 72px） | `EpisodePlayer.tsx` 底栏 `barRef` 区块、`seekHint` |
| 5 | 微光开关位置 | 无（封面虚化 `hg-lb-blur` 是另一套，已随本版删除） | **设置 › 播放 › 微光效果**，默认开，文案「画面颜色会轻微扩散到黑边，关闭可省电」；播放页里**没有**这个开关。实现是 32×18 采样画面主色填黑边 | `Settings.tsx`（播放组）、`AmbientGlow.tsx` |
| 6 | 平衡音量 | 无 | **设置 › 播放 › 平衡音量**，**默认关**；只有移动端且内核支持 MSE + Web Audio 时才出现这一行（桌面不显示） | `Settings.tsx`（`isMobile && isBalanceVolumeSupported()`）、`balanceVolume.ts` |
| 7 | 结束态「重新看第 1 集」 | 单集剧点它不重播（`pickEp(1)` 对已是第 1 集是空操作） | 单集剧走 `VideoSurface.rewind()`：倒回 **0** 并**无条件起播**，同时重新武装片尾兜底（否则 iOS 第二次到片尾不再补 `ended`）；多集剧照旧换集重载，换源期间用封面垫住尾帧。结束态**上滑一次只关卡片、不切剧**，再滑才切 | `EpisodePlayer.tsx` 结束卡、`VideoSurface.tsx` `rewind()` |
| 8 | 「拖到顶部胶囊锁倍速」 | 长按后拖到顶部胶囊＝把 2x 常驻锁定，另有下滑 0.5x | **整条交互删除**（上游 #193）：只剩长按 600ms 临时 2x、松手恢复；持久倍速走全屏倍速按钮。倍速提示条跟着控件一起隐藏 | `EpisodePlayer.tsx`（`holdSpeed`、倍速提示条） |
| 9 | 锁定态解锁钮 | 常驻 56px 白钮 | 锁定后画面干净，**第一次点屏幕才出现**解锁钮 + 「轻触即可解锁」提示，2200ms 后一起收起（上游 #194） | `PlaybackLock.tsx`（`hideUnlockUntilTapped` / `revealUnlock`） |
